Index backfill tool

Admin only. This reads every existing chat, offer, and transaction and writes the matching userChats / userOffers / userPropertyOffers / userTransactions entries so old records become visible again under the new rules. Safe to run more than once — it only ever writes true flags, never deletes anything. You must be signed in on this browser with an account listed under /admins in the database, or every write below will fail.
